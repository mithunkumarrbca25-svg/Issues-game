# Issues Game 🎮

A GitHub-based three-stage event game.

## How it works

1. **Game 1 — The Broken README**: solve the README investigation and submit your answer in Issue #1.
2. **Game 2 — GitHub Detective**: after Game 1 is verified, continue to Issue #2 and investigate the repository history.
3. **Game 3 — Race Against the Commit**: after Game 2 is verified, watch for the event clue commit, solve it, create `final-answer.txt`, and submit the commit link in Issue #3.

## Participant format

Use the same GitHub account throughout the event.

When submitting an answer, comment:

```
/answer YOUR_ANSWER
```

The event bot checks the answer and records your progress through issue comments.

> Organizers should configure the three answer secrets in the repository before the event:
> `GAME1_ANSWER`, `GAME2_ANSWER`, and `GAME3_ANSWER`.
