# Game 2 — GitHub Detective

You have reached the repository-history challenge.

Your task is to investigate the commit history and identify the **commit message used by the repository's first commit**.

### How to investigate

Open the repository's **commits/history** view and move to the oldest commit. Open that commit and read its commit message.

Then return to **Issue #2** and submit:

```
/answer <exact commit message>
```

The automated checker ignores capitalization and surrounding whitespace.

### Important

Do not guess from the current README. Use the actual Git history.
