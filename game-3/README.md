# Game 3 — Race Against the Commit

This is the final contribution challenge.

The organizer will publish a new commit containing a file named `final_clue.txt` when the round begins.

## Your task

1. Watch the repository's commit history.
2. Find the new `final_clue.txt` commit.
3. Read the clue.
4. Create a file named exactly:

```
final-answer.txt
```

5. Put your solved answer inside that file.
6. Commit and push it to your branch.
7. Return to **Issue #3** and comment with:

```
/answer <your solved answer>
Commit: <link to your commit>
```

The organizer will verify the final contribution and commit.

> The final clue is intentionally not present yet. The organizer controls when it is released.
